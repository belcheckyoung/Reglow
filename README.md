# ReGLOW

让闲置的 iPhone、iPad 重新亮起来，变成一块常亮的信息屏。

这个仓库放 ReGLOW 正式环境里所有可以公开的东西。App 本身不自带任何场景，场景都从这里（或任何人自己的仓库）通过链接添加。

## 目录

`scenes/<场景包名>/`：场景包的源文件与说明。每个场景包的签名文件（.reglowpack）随 Release 发布，在 App 里粘贴 Release 里的文件链接即可添加。

`docs/`：作者说明、格式说明等公开文档（陆续补充）。

## 添加场景

在 ReGLOW 里打开「添加场景包」，粘贴 .reglowpack 的 https 链接，或者选本地文件。App 会先检查签名，并列出这个场景包会用到的权限（联网的网站、设备状态、提醒事项、自带字体），你同意后才会添加。

## 说明

这里的场景和其他人做的场景一样，没有特殊权限。各场景使用的数据、字体与图片按各自目录里的说明和许可。
